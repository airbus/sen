# Archive record test

This directory has a simple recording file that works as an example to test cli_archive.

The recording can be generated by running sen with the archive_record.yaml:

1. Put the python script in your environment:
   `export PYTHONPATH=$PYTHONPATH:<path_of_this_repo>/apps/cli_archive/test/data`

2. Run the code and let it finish:
   `cd <path_of_this_repo>/apps/cli_archive/test/data && sen run archive_record.yaml`

3. A `archive_recording` directory should be generated in your working directory
