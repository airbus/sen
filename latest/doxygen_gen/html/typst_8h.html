struct sen::gen::TypstOptions

What the document contains and how it is put together. Every field defaults to the whole model and the standard sections, so a default-constructed value produces a complete document and a caller who wants that need know none of this.

Class Members
string title {"Data model"} Shown on the title page and in the running header.

bool overview {true} The overview: the package table and the class hierarchy across all packages.
bool hierarchy {true} The class hierarchy within the overview. Emitted only where classes inherit.
bool summaries {true} The per-section table of every type with its description and page.
