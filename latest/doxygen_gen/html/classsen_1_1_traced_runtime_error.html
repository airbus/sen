Detailed Description

A runtime error carrying the stack trace of where it was thrown.

It derives from std::runtime_error alone, so it has a single std::exception base and every handler for either of those matches it. cpptrace's own error types reach std::exception by a separate path, which is why the trace is held rather than inherited.

The trace is held behind an opaque pointer and read as text, because this header is included almost everywhere and naming a cpptrace type here would put that library on every consumer's include path.
